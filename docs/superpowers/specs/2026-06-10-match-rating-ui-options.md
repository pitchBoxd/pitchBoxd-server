# 경기 평점 UI 레이아웃 및 디자인 시안

팬들이 매긴 홈/원정/중립 삼색 평점 데이터의 화면 내 배치 및 시각적 표현 방식에 대한 2가지 디자인 시안입니다.

---

## 시안 1: [스코어보드 일체형 통합 바 (Scoreboard Integrated Bar)]

경기 상세 화면 맨 위의 스코어보드 바로 아래(또는 스코어보드 내부 하단)에 공통 경기 정보와 평점을 하나의 영역으로 결합하는 레이아웃입니다.

### 1) 구조화된 레이아웃 (Layout Mockup)
```
+--------------------------------------------------------------+
|                        K-LEAGUE 1                            |
|             FC 서울   3   :   2   수원 삼성                  |
|             2026.06.10 | 서울 월드컵경기장                     |
+--------------------------------------------------------------+
|  팬 경기 평점: ⭐ 7.8 / 10  (342명 참여)                      |
|                                                              |
|  [ 홈팬(서울) 🔴 9.2 ]   [ 원정팬(수원) 🔵 3.4 ]   [ 중립팬 🟢 8.1 ] |
+--------------------------------------------------------------+
```

### 2) 특징 및 흐름
* **위치**: 페이지의 최상단 헤더
* **디자인 톤**: 홈팀/원정팀의 선호 구단 컬러를 🔴, 🔵 서클 뱃지로 표현하고 중립팬은 🟢로 깔끔하게 대비시킵니다.
* **장점**: 경기 상세 페이지에 진입하자마자 경기의 결과(스코어)와 팬들의 평점 반응(경기 재미/편향도)을 스크롤 없이 단숨에 파악할 수 있습니다.
* **단점**: 사용자가 아직 이 경기를 평가하지 않았을 때 "평점 입력 유도 영역"이 이 정보와 겹쳐서 배치되기 어려워, 입력 폼의 위치를 따로 잡아야 합니다.

---

## 시안 2: [우측/하단 이원화 카드 (Dynamic Assessment Card)]

경기 정보(스코어보드)는 객체 정보만 보여주고, 평점 통계 및 내 입력 폼은 그 바로 아래에 배치되는 독립적인 동적 카드 형태의 레이아웃입니다.

### 1) 구조화된 레이아웃 (Layout Mockup)

#### [사용자가 평점을 매기기 전]
```
+--------------------------------------------------------------+
|             FC 서울   3   :   2   수원 삼성                  |
+--------------------------------------------------------------+
|  🤔 이 경기는 어떠셨나요?                                     |
|  [ ☆  ☆  ☆  ☆  ☆  ☆  ☆  ☆  ☆  ☆ ]  (클릭하여 평점 주기)     |
+--------------------------------------------------------------+
```

#### [사용자가 평점을 매긴 후]
```
+--------------------------------------------------------------+
|             FC 서울   3   :   2   수원 삼성                  |
+--------------------------------------------------------------+
|  내 평점: ⭐ 8.0  "기성용 원더골로 극적인 승리!" [수정]        |
|  ----------------------------------------------------------  |
|  전체 팬 평점: ⭐ 7.8                                        |
|  홈팬 🔴 9.2     |     원정팬 🔵 3.4     |     중립팬 🟢 8.1     |
|                                                              |
|  평점 분포: (Letterboxd 스타일 히스토그램)                     |
|  10 ★ | ■■                                                   |
|   9 ★ | ■■■■■                                               |
|   8 ★ | ■■■■■■■■■ (내 투표)                               |
|   7 ★ | ■■■■                                                 |
|   ... |                                                      |
+--------------------------------------------------------------+
```

### 2) 특징 및 흐름
* **위치**: 스코어보드 바로 하단
* **디자인 톤**: 사용자가 평가를 완료하는 순간 카드가 회전하거나 슬라이드되는 부드러운 전환 효과를 주어, 본인의 평가 요약과 함께 전체 삼색 평점 정보가 동적으로 나타납니다.
* **장점**:
  1. 평가 전과 후의 사용자 흐름이 매우 자연스럽고 매끄럽습니다.
  2. "내 평점"과 "전체 평점", 그리고 "삼색 지표" 및 "분포 그래프"를 하나의 맥락(Context) 안에서 모두 조화롭게 시각화할 수 있습니다.

---

### 추천안 및 의사결정

* **구현 범위와 UX 확장성 측면**에서 **[시안 2 (이원화 카드)]** 방식을 추천합니다. 
* 사용자가 본인의 평가를 완료한 뒤, 그 자리에 팬들의 집단지성 평점(홈/원정/중립 대비 및 분포 차트)이 드러나는 방식이 사용자의 성취감(Gamification 요소)과 참여 유도에 매우 뛰어난 UX이기 때문입니다.
