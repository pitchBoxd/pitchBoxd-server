## 2. 각 기기별 동작 방식

### ① 모바일 환경: 바텀 시트 (Bottom Sheet) - 이미지 좌측
* **진입**: 경기 상세 화면의 라인업 목록에서 특정 선수(예: Kevin De Bruyne) 카드를 터치합니다.
* **동작**: 화면 하단에서 부드럽게 위로 반쯤 슬라이드업되는 **바텀 시트**가 띄워집니다.
* **내부 구성**:
  * 선수의 프로필 이미지 및 이름
  * 팬들이 매긴 **평균 평점 (예: 8.4)**
  * 로그인 유저 본인이 평점을 줄 수 있는 슬라이더/별점 바
  * 다른 팬들이 남긴 **생생한 한줄평 목록 (Scrollable)**
* **이탈**: 시트 외부 영역을 터치하거나 시트 상단의 핸들러(`-` 모양)를 아래로 쓸어내려(Swipe Down) 닫을 수 있습니다. 경기 상세 화면의 컨텍스트(라인업 목록)가 그대로 유지되므로 인지적 단절이 없습니다.

### ② 데스크톱/PC 환경: 사이드 레이어 모달 (Side Drawer) - 이미지 우측
* **진입**: 라인업 테이블에서 선수를 클릭합니다.
* **동작**: 화면 우측 끝에서 부드럽게 미끄러지듯 나타나는 **슬라이드인 사이드 모달(Side Drawer)**이 등장하며, 동시에 본문 배경은 반투명하게 어두워집니다(Dimmed).
* **내부 구성**:
  * 선수 기본 정보 및 핵심 요약
  * **팬 한줄평 피드 (Fan Reviews)**: 스크롤하여 모든 한줄평을 끊김 없이 읽을 수 있습니다.
  * **나의 평가 영역**: 우측 팝업 안에서 곧바로 별점을 선택하고 한줄평을 남깁니다.
* **이탈**: 모달 우측 상단의 `X` 버튼을 누르거나, 어두워진 배경 영역(Dimmed Area)을 클릭하면 모달이 부드럽게 사라집니다.

## 3. 이 방식이 주는 혜택 (UX Benefits)
1. **페이지 전환 제로 (Zero Page Navigation)**:
   선수 정보를 보거나 평점을 남길 때마다 새로운 페이지로 이동해야 한다면, 뒤로 가기 버튼을 계속 눌러야 하는 엄청난 불편함이 생깁니다. 모달 방식을 사용하면 경기 상세 화면이라는 **하나의 컨텍스트 안에서 모든 선수를 연속적으로 신속하게 평가**할 수 있어 참여율을 비약적으로 높입니다.
2. **정보의 밀도 조절**:
   평소에는 전체 라인업의 평균 평점만 콤팩트하게 훑어보다가, 관심 있는 선수만 골라 한줄평과 상세 분포를 팝업으로 깊이 있게 볼 수 있으므로 피로감이 적습니다.
